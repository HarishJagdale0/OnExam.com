# 📝 OnExam.com
**OnExam.com** is a powerful, flexible, and secure platform for creating and managing **online exam portals**. ## 🚀 Features 

* ✅ **Create Custom Exam Portals** – White-labeled portals for institutions or organizations
* 🧠 **Question Bank Management** – Add, import, and categorize questions (MCQs, subjective, coding, etc.)
* ⏱️ **Timed Exams** – Configure start/end times, duration, and auto-submission
* 🔐 **Secure Exam Environment** – Full-screen mode, tab-switch detection, IP restrictions, webcam proctoring
* 📊 **Real-Time Analytics & Results** – Instant scoring, rank generation, and performance insights
* 👨‍🏫 **Admin & Instructor Dashboards** – Manage users, exams, questions, and reports
* 🎓 **Student Dashboard** – Seamless exam-taking experience with personalized profiles
* 🌐 **Multi-device & Responsive** – Works on desktops, tablets, and mobiles
* 🔄 **API Integration Support** – Integrate exam functionality into your existing platforms
* 🔔 **Notifications & Reminders** – Email and SMS alerts for exams and results

## 🛠️ Use Cases

* **Schools & Colleges** – For internal assessments, semester exams, quizzes
* **Recruitment Portals** – For pre-hiring assessments and aptitude tests
* **Certification Bodies** – For delivering professional certification exams
* **Coaching Institutes** – For mock tests, practice sessions, and evaluations

## 🔧 Installation (Developer Setup)

1. Clone the repository

```bash
git clone https://github.com/yourusername/OnExam.com.git
cd OnExam.com
```

2. Install dependencies

```bash
npm install
# or
pip install -r requirements.txt
```

3. Configure environment variables

```bash
cp .env.example .env
# Edit .env with your settings
```

4. Run development server

```bash
npm start
# or
python manage.py runserver
```
